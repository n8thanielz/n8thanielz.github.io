Small tools for a big spreadsheet problem

I'm Nate Zwart, Program Director for the School of Accounting at the University of Utah's David Eccles School of Business. A lot of my job runs on schedules, syllabi, and spreadsheets that have outgrown themselves. This page collects the browser-based tools I've built to make that work faster and harder to break.

Everything here is a personal project hosted on GitHub Pages. These aren't official University of Utah websites.

How they work

Each tool is a single web page that runs in your browser. There's nothing to install and no account to create. Most of them keep your data on your own computer and let you save or export a file when you're done.

The Curriculum Analyzer uses the Anthropic API to read syllabi. The API key you enter stays in your browser and is only sent to Anthropic when you run an extraction.

Why build them

Our department's value is Students First. Every hour saved on schedule wrangling and spreadsheet repair is an hour that goes back to advising, curriculum, and the students we're here for.

I build these with Claude Code and keep the code on GitHub so colleagues can see how they work and pick them up later.

Privacy

Short version: I don't collect anything about you, and I can't see what you do in these tools.

This site

There are no accounts, cookies, ads, or analytics trackers on this page or the tools linked from it. I don't receive any information about who visits.

Data you enter in the tools

The tools run entirely in your browser. Files you load and changes you make are stored on your own computer, in your browser's local storage, and stay there until you clear them. Nothing is sent to me or saved on a server I control. To keep or share your work, use each tool's save or export option.

Curriculum Analyzer and the Anthropic API

When you run an extraction, the syllabus you uploaded and the API key you entered are sent directly from your browser to Anthropic's API (api.anthropic.com) so Claude can read the document. Nothing else is sent, and nothing goes anywhere until you click Run Extraction. Your API key is saved only in your browser. How Anthropic handles that data is covered by the terms of the API account the key belongs to.

The tool never asks for your University of Utah login, passwords, or personal information. If any page here ever does, it isn't mine.
